# إدارة رزنامة السعودية — الدخول والنشر الآمن

تم نقل حفظ التعديلات من طلب GitHub مباشر داخل المتصفح إلى خادم مستقل. واجهة GitHub Pages لا تحتوي على مفتاح GitHub أو كلمة مرور المدير.

## البنية

- الواجهة العامة: https://youef.github.io/Zyad/
- الإدارة: https://youef.github.io/Zyad/admin/
- خدمة الإدارة: https://zyad-admin-api-yousef8-15e4.vercel.app/api/zyad
- مشروع Vercel: `zyad-admin-api`
- مصدر الخدمة: `api/zyad.js`

## إعداد الخدمة (مرة واحدة)

افتح مشروع `zyad-admin-api` في Vercel → Settings → Environment Variables، وأضف المتغيرات التالية بإعداد **Encrypted / Sensitive** وبيئة **Production**:

| الاسم | المطلوب |
| --- | --- |
| `ZYAD_ADMIN_USERNAME` | اسم المستخدم الذي تختاره؛ الافتراضي `admin` |
| `ZYAD_ADMIN_PASSWORD` | كلمة مرور قوية لا تقل عن 12 رمزًا |
| `ZYAD_GITHUB_TOKEN` | رمز خدمة GitHub مُقيّد بالمستودع `youef/Zyad` وصلاحية `Contents: Read and write` |

ثم أعد نشر الـ deployment في Vercel. للتحقق افتح:

`https://zyad-admin-api-yousef8-15e4.vercel.app/api/zyad?action=status`

يجب أن يعرض `{"ok":true,"ready":true}`. إذا ظهر `ready:false` فهذا يعني أن بعض المتغيرات غير مُهيّأة.

> هذا الإعداد لا يطلب أي رمز من زائر لوحة الإدارة. رمز GitHub يُضبط مرة واحدة في إعدادات **الخادم فقط**. لا تضعه في JavaScript أو ملف داخل GitHub أو المحادثات.

## الحفظ والنشر

1. ادخل إلى صفحة الإدارة باستخدام اسم المستخدم وكلمة المرور.
2. عدّل المحتوى أو القوالب أو الأحداث، وشاهد المعاينة الفورية.
3. اضغط **حفظ التعديلات ونشرها**.
4. يتحقق الخادم من الجلسة ومن أن نسخة البيانات لم تتغير أثناء التحرير، ثم يُحدّث `data/config.json` في فرع `main`.
5. يقوم GitHub Actions بتنفيذ الاختبارات وإعادة بناء الصور والموقع.

الزر القديم الذي يستخدم Personal Access Token داخل المتصفح أُزيل بالكامل. الخطأ 403 قد يستمر فقط إذا كان رمز **الخادم** بلا صلاحية؛ ستظهر رسالة دقيقة بدل الادعاء بأن النشر نجح.

## الأمان

- واجهة التحرير لا تُشغّل وحدات الإدارة قبل التحقق من الجلسة على الخادم.
- مدة الجلسة 8 ساعات، ويُحفظ إثبات الدخول في `sessionStorage` فقط حتى إغلاق الجلسة.
- يجري التحقق من اسم المستخدم وكلمة المرور على الخادم. لا يتم تضمينهما في الملفات المنشورة.
- حماية مصدر الكتابة موجودة في الخادم، وليس في إخفاء عناصر الواجهة فقط.
- الـ API يقبل طلبات المتصفح فقط من `https://youef.github.io` ويرفض عمليات الكتابة دون مصادقة.
- يلزم تفعيل **Vercel Firewall Rate Limiting** لتحقيق حماية موزعة من المحاولات المتكررة؛ المحدّد المحلي في الوظيفة وحده ليس حماية شاملة على جميع النسخ.
- محتوى `data/config.json` عام لأنه يغذي تطبيق الزوار، لذا لا تخزن فيه كلمات مرور أو بيانات خاصة.
- لا تحفظ كلمة المرور في البريد أو الشيفرة أو README.

## ملاحظات تقنية

نُشرت خدمة Vercel أوليًا بنشر ملفات مباشر، وليست مربوطة تلقائيًا بمستودع GitHub حاليًا، لأن تكامل GitHub لدى حساب Vercel لم يكن مفعّلاً وقت الإعداد. أي تحديث مستقبلي على `api/zyad.js` يتطلب إعادة نشر وظيفة Vercel أو ربط المستودع بتكامل GitHub رسميًا. واجهة GitHub Pages يتم نشرها تلقائيًا بواسطة GitHub Actions.

للتصميم اعتمدنا الدليل `apple-ui-designer_SKILL.md`: خطوط نظامية، عناوين واضحة، أسطح هادئة، تباين لطيف، تنقل مريح باللمس، واحترام المساحات الآمنة في الجوال.
