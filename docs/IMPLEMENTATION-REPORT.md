# بطاقتي الذكية — تقرير التطوير 2.0

## المنفذ
- الحفاظ على الموقع والتقويم والإعدادات والأرشيف وستة قوالب التقويم القديمة.
- هوية عربية زمردية وعاجية وذهبية، خط Cairo محلي، SVG، RTL، استجابة للجوال، وضع داكن/فاتح محفوظ، واحترام تقليل الحركة.
- **24 خلفية PNG أصلية + 8 زخارف PNG شفافة + 24 قالبًا جديدًا**، إضافة إلى القوالب الستة السابقة. نسخ WebP محسنة، سجل أصول، وملفات JSON بإصدار 2.
- إنشاء لوحة هوية وقالبَي جمعة وتخرج قابلة للتحرير في [Canva](https://canva.link/gup4y1ntpz6gvbp).
- محرر طبقات للنص والصور والأشكال والزخارف والتوقيع والتاريخين والعد التنازلي وQR. سحب وتحجيم، ترتيب وقفل وإخفاء ونسخ وحذف، تراجع وإعادة، وتوسيط وخيارات متقدمة.
- PNG وJPEG وWebP بأربعة مقاسات، ودقة 2×، مشاركة ملف عند دعم الجهاز وتنزيل بديل، نسخ النص والرابط، وحزمة تقويم أسبوعية ZIP.
- مكتبة محلية للتصاميم والمسودات والمفضلة والصور والأرشيف والسلة، مع مشاريع JSON ونسخة احتياطية واستعادة كنسخ إضافية.
- نسخ المسودات القديمة إلى المكتبة مع إبقاء الأصل ونسخة احتياطية قبل النقل.
- تقويم ميلادي وأم القرى بمدى 1، 3، 6، 12، 24 شهرًا، أحداث شخصية متكررة، تفاصيل وتوقيت ومصدر عند توفره، ICS وبطاقة عد تنازلي من الحدث.
- إدارة الأصول المحلية، قواعد قالب اليوم حسب اليوم/الأولوية، سجل توليد، ومراجعة تعارض إعدادات GitHub قبل النشر.
- PWA يعمل دون اتصال للواجهة والعناصر المستخدمة، تخزين مؤقت محدود، وتحديث الواجهة دون مسح المسودات.

## التحقق
نجحت اختبارات التواريخ والعقود، ومنها نهاية الشهر والسنة الكبيسة والتكرار السنوي ليوم 29 فبراير وأولوية القواعد. اختبارات Chromium بمقاسي 390×844 و1440×1000 تتحقق من الصفحات والقوالب والتعديل والحفظ والرفع والتراجع والإعادة والقفل، وتصدير الصيغ الثلاث بالأحجام الأربعة، وقراءة QR من الصورة المصدرة، والعمل دون اتصال وعدم وجود أخطاء JavaScript.

اختبارات إضافية للسحب بالماوس، رفض المشاريع التالفة، فشل التصدير ثم نجاح إعادة المحاولة، PNG بدقة 2160×3840، نقل مسودة قديمة مع نسخة احتياطية، وحفظ المظهر الداكن. النتائج والصور في `images/verification/`. استُخدم Chromium؛ لم يُختبر هاتف iPhone فعلي أو Safari فعلي.

## الحدود الفعلية
- لا توجد حسابات أو مزامنة سحابية أو صلاحيات متعددة المستخدمين؛ البيانات محلية كما يظهر في المكتبة. الإعدادات المنشورة فقط تحفظ على GitHub بصلاحيات المستودع.
- رفع الأصول من الإدارة محلي. إتاحتها للعامة يحتاج إضافتها للمستودع وفق دليل الأصول، ولا تدّعي الواجهة أنها نُشرت.
- لا يوجد نشر آلي إلى واتساب أو سناب؛ المشاركة عبر واجهة الجهاز الرسمية عند دعم مشاركة الملفات.
- لا يوجد MP4 لأن خدمة تصيير فيديو لم تُجهّز. الصور الثابتة متاحة دائمًا.
- القواعد اليومية تختار قالب بطاقة الاستوديو المنشورة في `images/smart-latest.png`؛ تقويم المواعيد اليومي التقليدي يستمر مستقلًا.
- المواعيد الموروثة تقديرية؛ لم تُضف تواريخ رسمية حديثة أو مصادر مختلقة.
- معاينات خلفيات الاستوديو ورسوماتها وCanva مستقلة؛ بيانات طبقات التطبيق لا تتزامن تلقائيًا مع محرر Canva.
