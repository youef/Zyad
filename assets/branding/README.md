# الهوية الرسمية | رزنامة السعودية

الشعار الرسمي المستخدم حاليًا: `assets/branding/logo.png`.

- يظهر في شريط الهوية داخل التطبيق وصفحات الإدارة والاستوديو والقوالب.
- يظهر داخل صور التقويم (42 قالبًا)، وقوالب التصميم الحر (24 قالبًا) مع المحافظة على أبعاد الصورة ودون قص.
- يولّد `scripts/prepare-brand-icons.mjs` أيقونات التطبيق `assets/app-180.png` و`assets/app-192.png` و`assets/app-512.png` من الشعار نفسه عند البناء.
- لتغيير الشعار رسميًا، استبدل `logo.png` بنفس المسار، أو اختر شعارًا آخر مخصصًا من لوحة الإدارة للبطاقات.
