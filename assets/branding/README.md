# هوية المنصة | Branding

هذا المجلد مخصص للشعار الرسمي للموقع.

## رفع الشعار

1. ارفع صورة الشعار **رزنامة السعودية | SAUDI CALENDAR** باسم `logo.png` داخل هذا المجلد.
2. استخدم **PNG شفاف الخلفية** بدقة عالية (يفضل 1024 بكسل أو أكثر).
3. للحصول على الأيقونة وحدها، يمكن لاحقًا رفع `icon.png` كمربع.

المسار: `assets/branding/logo.png`

رابط الصورة بعد رفعها: `https://youef.github.io/Zyad/assets/branding/logo.png`

> ملاحظة: رفع الصورة لا يستبدل شعار الواجهة تلقائيًا؛ يلزم تحديث موضع عرض الشعار في الواجهة عند اختيار اعتماده.
