# بطاقتي اليومية — Zyad

موقع عربي متجاوب لعرض بطاقة تقويم يومية مستوحاة من الطابع السعودي الأخضر والذهبي، مع لوحة تحرير وحفظ للأرشيف. يعمل للزوار بالكامل على **GitHub Pages** دون خادم دائم.

## الروابط بعد تفعيل GitHub Pages
- صفحة الزوار: https://youef.github.io/Zyad/
- لوحة الإدارة: https://youef.github.io/Zyad/admin/
- الصورة الأحدث: https://youef.github.io/Zyad/images/latest.png
- صور الأيام: `images/YYYY-MM-DD.png`

> مهم: تفعيل GitHub Pages من **Settings → Pages → Build and deployment → Source: GitHub Actions** خطوة يقوم بها مالك المستودع في GitHub؛ المستودع الجديد لا يُنشر تلقائيًا قبل هذا الإعداد.

## طريقة الإدارة
1. افتح `/admin/`، عدّل الاسم والشعار والمحتوى والألوان والعدادات. المعاينة والتنزيل يعملان دون تسجيل.
2. إنشاء رمز **fine-grained personal access token** في GitHub، محدود بمستودع **youef/Zyad** وبصلاحية **Contents: Read and write**. تجنّب الرموز العامة واسعة الصلاحيات.
3. الصق الرمز في تبويب «الحفظ والنشر» واضغط «حفظ ونشر للزوار». لا يُكتب الرمز في GitHub أو التخزين المحلي، لكنه يظل في حقل الصفحة وذاكرتها حتى إغلاقها. احمِ جهازك ومتصفحك.
4. يعتمد التعديل على GitHub Contents API، الذي يتحقق من الصلاحيات عند الحفظ. عنوان `/admin/` **عام للعرض**، لكنه لا يمنح صلاحية الكتابة دون رمز GitHub مخوّل.
5. يطلق الحفظ على `main` إجراء GitHub Actions لإعادة توليد الصورة والنشر. تابع تبويب Actions إن لم يظهر التحديث.

**أمان إضافي:** إذا أردت تسجيل دخول إداري بدون إدخال GitHub Token في المتصفح، يلزم Backend مع جلسات مصادق عليها (مثل Supabase Auth + Edge Function)، ولا توفر GitHub Pages وحدها هذه الميزة.

## آلية التوليد
- حساب مواعيد ميلادية وشهرية محليًا في `assets/card.js` اعتمادًا على تاريخ البطاقة المحدد.
- التاريخ الهجري بحسب تقويم أم القرى المتوفر لدى المتصفح، مع إمكانية فرق أيام أو إدخال نص مخصص. قد تختلف بعض المناسبات عن الإعلان الرسمي.
- عرض الملصق باستخدام Canvas بمقاس أصلي **1080×1920** بكسل.
- GitHub Actions يشغل Chromium عبر Playwright ويحتفظ بالنسخة الجديدة تلقائيًا عند 01:10 بتوقيت السعودية، أو بعد تعديل الإعدادات، أو عبر التشغيل اليدوي.
- رمز QR يولد من الرابط المدرج عبر حزمة `qrcode` أثناء التوليد الآلي؛ قد لا يظهر التغيير في المعاينة المحلية قبل اكتمال دورة النشر.
- تُخزن الصور اليومية في `images/`، والسجل في `data/history.json`. إذا كان `archiveDays=0` فلا حذف تلقائي للصور القديمة. راقب حجم مستودع Git مع الاستعمال الطويل.

## تطوير محلي
```bash
npm install
npx playwright install chromium
npm run render
python3 -m http.server 8000
```
افتح `http://localhost:8000` أو `http://localhost:8000/admin/`.

## ما ينبغي تخصيصه قبل مشاركة البطاقة
- معلومات الاشتراك وأرقام التواصل والشعار؛ الإعداد الافتراضي لا يحتوي على رقم هاتف من الصورة المرجعية.
- مواعيد الدعم، بداية رمضان، الفصول ومكافآت الجامعة هي **إعدادات توضيحية قابلة للتعديل** وليست إعلانًا رسميًا ولا تتصل بجهات الصرف تلقائيًا. المدفوعات قد تتغير بسبب الإجازات أو قرارات الجهات.
- مصدر العبارة والتأكد من نصوصه قبل نشرها، ورابط رمز QR.

## ملفات المشروع
- `index.html`: صفحة المشاهدين والأرشيف.
- `admin/index.html`: محرر الإدارة.
- `assets/card.js`: محرك رسم وتواريخ البطاقات.
- `assets/admin.js`: إدارة الإعدادات والنشر عبر GitHub API.
- `data/config.json`: النسخة المنشورة من إعدادات البطاقة.
- `scripts/render.mjs`: التوليد التلقائي والحفظ.
- `.github/workflows/daily.yml`: مهمة التوليد والنشر المجدولة.
