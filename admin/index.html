الاشتراك والمتابعة تحت الإعلان

تظهر هذه المساحة داخل جميع البطاقات، أسفل صورة الإعلان، وتتكيف تلقائيًا مع ألوان القالب ومقاس التصميم. أي تغيير يظهر في المعاينة ثم يُنشر عند الضغط على حفظ ونشر.

المعاينة على البطاقة تُحدّث تلقائيًا.

يمكنك إضافة أي موعد، أو تعديل ترتيبه، أو إخفاؤه. شهري يتكرر حسب يوم الشهر، وتاريخ يحسب الأيام حتى الموعد، ويدوي يعرض الرقم الذي تكتبه.

استوديو القوالب الاحترافياضغط أي قالب لتطبيقه فورًا على البطاقة الفعلية. الصور أدناه معاينات حقيقية مولدة تلقائيًا.

النشر الآمن للمنصة

تُرسل التعديلات إلى خادم خاص يتحقق من جلسة المدير ثم يحفظها في GitHub، دون عرض أي رمز وصول داخل المتصفح.

بعد النشر تقوم GitHub Actions بتحديث بطاقة اليوم والموقع.

يُعاد توليد الصورة تلقائيًا عند نشر تعديلات الإعدادات، وكذلك يوميًا بعد منتصف الليل بتوقيت السعودية بواسطة GitHub Actions.
