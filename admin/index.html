إدارة المحتوى

خصّص بطاقتك

تظهر التعديلات في المعاينة فورًا، ويمكن نشرها لجميع المشاهدين بعد ربط حساب GitHub.

تظهر اسم البطاقة وشعارها في أعلى التصميم وواجهة الموقع.

يمكنك إضافة أي موعد، أو تعديل ترتيبه، أو إخفاؤه. شهري يتكرر حسب يوم الشهر، وتاريخ يحسب الأيام حتى الموعد، ويدوي يعرض الرقم الذي تكتبه.

يستخدم التقويم الهجري حسب «أم القرى» في المتصفح مع إمكانية التصحيح اليدوي. عدّل موعد رمضان إذا أعلنت الجهة الرسمية تاريخًا مختلفًا.

حفظ دائم على GitHub

الزائر يستطيع العرض والتنزيل فقط. لحفظ تعديلاتك للجميع، استخدم رمز وصول GitHub بصلاحية Contents: Read and write على مستودع youef/Zyad.

الرمز يبقى في ذاكرة هذه الصفحة أثناء فتحها فقط؛ لا يُخزّن داخل المشروع أو المتصفح. لا تشارك الرمز مع أحد.

يُعاد توليد الصورة تلقائيًا عند نشر تعديلات الإعدادات، وكذلك يوميًا بعد منتصف الليل بتوقيت السعودية بواسطة GitHub Actions.
